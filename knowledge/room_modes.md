# Room Modes

## Summary

Les modes propres sont des résonances naturelles d'une pièce.

## Symptoms

- pic étroit dans le grave
- grave boursouflé
- réponse différente selon la position

## Causes

- dimensions de la pièce

## Diagnostics

- mesure REW
- calcul théorique

## Solutions

- déplacer les enceintes
- déplacer le point d'écoute
- bass traps
- égalisation
